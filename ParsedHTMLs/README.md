# ParsedHTMLs – сурови HTML файлове по сайт

Тук се пазят **изтеглените (сурови) HTML** файлове на статии, групирани по уебсайт.

## Структура

- **`<site_id>/`** – една подпапка на сайт (напр. `birgun.net/`).
- Вътре в нея – по един `.html` файл на статия, с разпознаваемо име (напр. от slug в URL).

## Текущи сайтове

- **birgun.net** – статии от BirGün Gazetesi (www.birgun.net).  
  Схема и правила за извличане: виж **Schemas/birgun.net/** и **Schemas/sites.json**.

Списъкът с регистрирани сайтове и пътища до схемите им е в **Schemas/sites.json**.
